StillAura


A browser extension helps users to be calm, attentive and keep ourselves safe from digital distractions.

Overview : 
Sometimes we spend too much time on our laptops, switching between websites, watching videos or just scrolling without any reason.
To solve this problem we have StillAura which is your 5 minute window away from all distractions, soft animations , guided breathing exercise to keep ourselves calm and retain attention.


Features
5-minute relaxation session.
Guided breathing .
Floating particles and smooth wave animations.
A glowing breathing sphere in the centre.
Relaxing background sounds.
Sound on/off and volume control.
Fullscreen mode for a better experience.
No complicated setup required.

Languages and API’s used are : 

HTML

CSS

JavaScript

Chrome Extension Manifest V3

Web Audio API

Project Structure

manifest.json – Contains the extension settings.


popup.html – Extension popup interface.

popup.css – Styling for the popup.

popup.js – Popup functionality.

reset.html – Main relaxation screen.

reset.css – Animations and overall design.

reset.js – Timer, breathing animation and sound functionality.

Installation

Download or clone this repository: 

git clone https://github.com/username/stillaura.git

Open the browser and go to chrome://extensions/.

Turn on Developer mode.

Click on Load unpacked.

Select the StillAura project folder.

The extension should now appear in your browser extensions.
